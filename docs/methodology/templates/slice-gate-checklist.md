# 슬라이스 착수 게이트 체크리스트

> **이 문서의 책임**: 슬라이스(작은 증분)를 시작하기 전, Build 루프
> (`게이트 → 스펙 → 계획 → 격리 → TDD → 리뷰 → 검증 → 통합`)의 **게이트(재독)** 단계를
> 실제로 걷게 하는 실행용 체크리스트다. 아래 항목을 전부 표시하기 전에는 다음 단계(스펙)로
> 넘어가지 않는다.

## 체크리스트

### 1. 재독 (기억이 아니라 문서에서)

- [ ] `1-requirements.md`에서 관련 요구사항(`<REQ-...>`)과 수용 기준을 **다시 읽었다**.
- [ ] 이 요구사항이 걸리는 바운디드 영역을 `2-strategy.md`에서 확인했다: `<영역 이름>`
- [ ] 관련 빌딩블록/규칙을 `3-tactics.md`에서 확인했다: `<블록/규칙 ID>`
- [ ] 관련 스키마/쿼리를 `4-data.md`에서 확인했다(데이터를 건드리는 경우): `<...>`
- [ ] 헷갈리는 규칙 쌍이 있는지 `boundary-catalog.md`를 확인했다: `<해당 쌍 또는 "없음">`

### 2. 경계 확인

- [ ] 이 슬라이스가 건드리는 모듈/영역의 경계를 확인했다: `<경계 목록>`
- [ ] 이 슬라이스가 **다른 바운디드 영역의 소유 데이터/개념을 침범하지 않는지** 확인했다.
- [ ] 경계를 넘는 의존이 있다면 `2-strategy.md`의 컨텍스트 맵과 일치하는지 확인했다.

무엇을 읽고 무엇을 확인했는지 기록한다 — 증거로 남기며, 기억에 의존하지 않는다.
