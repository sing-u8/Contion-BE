# GEMINI.md — 진입 포인터 (Gemini)

이 파일은 Gemini가 세션 시작 시 자동으로 로드하는 진입 스텁이다. 본문을 복제하지 않고
헌법을 참조한다(C1 — 진실의 외부화를 이 파일 자신에도 적용).

> 이 저장소 행동 규칙의 최상위 기준은 `<repo>/docs/methodology/CONSTITUTION.md`다.
> **세션 시작 시 반드시 읽고 그대로 따르라.** (경로는 실제 저장소 구조에 맞게 설정한다.)

## 하드코어 미러 — 4개 비협상 항목 (Tier 0)

이 헌법은 채택 저장소에서 에이전트 행동의 **최상위 불변 기준(Tier 0)**이다. 어떤 스킬
팩·슬래시-커맨드·서브에이전트도 **기법 제공자**일 뿐이며, 다음 4개 비협상 항목을 절대
변경할 수 없다:

1. **게이트 순서** — 기획: 상위 재독 후 하위. 구현: 슬라이스마다 스펙 재독 후 진행.
2. **SSoT 우선** — 문서 > 코드.
3. **근거 인용** — 규칙은 원문 인용, 외워서 인용 금지.
4. **검증-전-완료** — 명령 실행·출력 확인 없이 "완료" 없음.

팩 기본동작이 위 4개와 충돌하면(자동 커밋 · 게이트 스킵 · 리뷰 우회 등) 이 조항이
이기고 그 동작은 무효다. 기계적 훅(git/CI)이 특히 1·4를 스킬과 무관하게 강제한다.

> 팩(예: 어떤 슬래시-커맨드 팩이든)은 기법 제공자일 뿐, 위 4항목을 못 바꾼다.
